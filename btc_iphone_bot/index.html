Important limitations

This is a browser-based learning simulator, not a Polymarket contract bot. It needs an internet connection and an open, active browser tab. iOS may suspend it when the phone locks or Safari is backgrounded. No push notifications or unattended 24/7 execution. Account history is saved only in this browser's local storage; clearing site data can erase it. Public exchange data can be delayed or temporarily unavailable.

Data: Coinbase Exchange public BTC-USD/candles and BTC-USD/ticker. No API key required.
